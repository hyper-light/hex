A legal observer handoff remains one Box holder while a canonical Creating/no-init Box record references the exact pool generation, same actual backend, full selected set and compatible immutable profile. Any foreign/stale/partial/extra claim or already-published Box native identity refuses. This is a claim fence, not permission for simultaneous physical attachment: native launch still requires the observer whole-scope release proof. Catalog::prepare(spec,boxes,pools) permits only that exact live observer grant, otherwise Busy/Invalid. It performs no pick, host bind or driver mutation.
