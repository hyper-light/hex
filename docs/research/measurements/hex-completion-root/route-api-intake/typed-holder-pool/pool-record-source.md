`PoolRecord::{scope,check,offer,accept_grant,accepts,native_commitment,encode,decode}` cover the pure contract. `accepts` freezes configuration, scope, physical claims and allocation, permits init introduction only Granted->Granted while native execution is held, freezes init after introduction, rejects conflicting terminal facts, and forbids Draining/Released rollback. An admitted Released row requires an exact terminal result; its own native owner supplies whole-scope proof, not a phase bit.
